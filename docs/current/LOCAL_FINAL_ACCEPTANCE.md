## 明确边界

- 未在新电脑实测；完整应用未在 Windows、Linux 验证。Ubuntu 上的 GitHub 类型检查和单元测试不等于完整安装或浏览器验收。
- 本地上传、人工处理和导出免费；AI 使用者自行配置密钥及额度，选中的文件会发给外部 API。
- 历史六份 AI 样本不是大样本准确率、商业效果或净省时证明；本次只整理发布，没有重新评测模型。
- 仅本机单用户使用；不启用客户远程入口、自动邮件、云连接器、多用户或公网部署。相关已有代码保留。
- 冷备份及同机恢复已有核对，跨机器数据库迁移未验证。没有一键安装包。
- 不自动记账、报税，不提供会计或合规正确性保证。演示使用虚构资料。

旧云端里程碑、多人测试和维护者个人收尾记录不作为此软件版本的验收要求。后续只按实际新增功能或修复重新验证相关部分。
