# Document Operations — Local

A local accounting document workflow: upload, real AI classification, human review, exception handling, handoff and history.

See [installation and limitations](platform/LOCAL_README.md), [demo guide](platform/DEMO_SCRIPT.md), and [six real API checks](platform/docs/evidence/LOCAL_CLOSEOUT_AI_RESULTS.json).

This is a release candidate. No real customer data, personal credentials, database, node_modules or private Git history is included. The original cloud adapters remain in the source; they are not enabled by the local launcher.
