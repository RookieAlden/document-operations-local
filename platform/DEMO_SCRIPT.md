# 3—5 分钟演示提纲

先按[完整示例](EXAMPLE_WALKTHROUGH.md)练习一遍，使用虚构资料和独立演示实例。录制不需要公开个人配置或 API 密钥。免费版本全程人工分类即可；若展示真实 AI，请先设置自己的额度，录制时主动调用，不以历史结果冒充现场调用。

| 时间 | 操作 | 可以解释什么 |
| --- | --- | --- |
| 0:00—0:30 | 展示员工工作台 | 收集会计资料，整理成可交接任务；不自动记账 |
| 0:30—1:10 | 新建客户、季度任务、三类资料要求 | 每个客户需要什么资料、缺多少可以看清楚 |
| 1:10—2:00 | 上传发票、收据、错期间文件；预览并分类 | 原件和业务记录保存在本机；AI 是可选外部服务 |
| 2:00—3:10 | 请求补交、排除错期间或无关文件，上传正确对账单 | 原件保留；缺件、待复核、开放问题会阻止交接 |
| 3:10—4:10 | 关闭问题、完成收集与后续任务，进入历史导出 | 得到可打印清单，重复操作不重复创建任务 |
| 4:10—4:40 | 展示已完成记录 | 当前支持本机使用；未验证真实客户节省工时 |

时间是镜头分配，不是处理速度承诺。AI 等待可以剪辑但应注明；调用失败时展示人工接管。软件版本的发布不依赖维护者个人视频是否录制完成。
