# 本人录屏提纲（3—5 分钟）

录制前：启动本地版本，准备六份虚构 PDF；先完成真实 AI 验收。检查浏览器没有显示密钥、个人目录和真实资料。选择空白演示实例，不重置已有资料。录制中的 API 调用与验收调用分开核算；6 次验收额度用完后，录制前需另行明确额度，不能通过删用量记录绕过。

1. **0:00—0:30：介绍用途。** “这是我做的会计资料工作台，用来把分散文件整理成可交接的资料任务。AI 提供分类建议，异常由人工确认。我这次展示完全运行在本机的版本。” 展示今日待办。
2. **0:30—1:10：从零建档。** 新建虚构客户 Blue Peak Consulting Limited，选季度工作，期间 2026 年第三季度；资料要求选择银行对账单、发票、费用收据各 1 份。说明资料要求可以按任务调整。
3. **1:10—2:10：上传并实时分类。** 上传标准三份文件，打开一份原件；主动触发真实 AI 分类。展示返回的类别与理由，按需人工确认或改类。等待时可说明“保存原件和业务记录在本机；只有主动分类时才发送选中的文件到 API”。如实际延迟较长可剪掉等待，但注明剪辑，不以预录结果冒充当场分类。
4. **2:10—3:10：展示异常与补交。** 使用错期间文件演示阻断交接，建立补交问题；上传正确文件，复核后排除错期间原件、关闭补交问题。排除不等于删除，原件仍可预览。必要时用园艺笔记演示无法归类后的人工排除。
5. **3:10—4:10：交接和导出。** 资料要求满足、问题解决后完成收集，展示唯一的后续交接任务；记录任务状态，进入已完成历史，打开清单并打印保存 PDF。
6. **4:10—4:40：收束。** “这个版本保留了上传、分类、人工处理和交接全过程；远程客户提交和自动邮件不在本地演示范围内。项目尚未做真实客户净节省时间测量，所以我把它定位为可以实际操作、可以继续修改的工作流程项目。”

录制前必须自己完整练习一次。以上时间是镜头分配，不是系统处理速度承诺。若 AI 当场失败，演示人工接管并如实说明；不要为了视频效果修改分类结果或伪造调用。
