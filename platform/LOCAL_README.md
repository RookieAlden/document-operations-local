# 本地资料工作台（收尾验收版）

本项目帮助整理会计资料：创建客户与资料任务、保存原件、AI 辅助分类、人工复核、处理缺件、完成交接和导出清单。它不自动记账或报税，也没有经过真实客户净省时或商业收益验证。

**当前状态：人工完整链路和六份文件的真实 AI 链路均已通过本机验收；重启后分类、原件、交接任务和费用记录保留。已按所有者确认公开发布至 https://github.com/RookieAlden/document-operations-local 。本人录屏及云资源停费尚未完成。**

## 安装与启动

要求 Node.js 22 或更新的兼容版本、pnpm（版本见 service/package.json）、PostgreSQL 17 的完整安装（含 pgcrypto）。目前实测平台为 macOS；Windows 未验证。数据库由本工具独立启动，不使用已有 DATABASE_URL，不连接云数据库。初次安装包管理器依赖仍需联网。

从仓库根目录运行：

```sh
cd platform/service
pnpm install --frozen-lockfile
node scripts/local/setup.mjs
node scripts/local/runtime.mjs start --pg-bin /你的/PostgreSQL17/bin
```

首次安装只配置一次自己的账号和密码；以后登录只填账号和密码，可由浏览器保存。再次运行 setup 会保留已有配置。当前所有者已配置的账号、密码保持不变，不随版本或演示数据重置而重新生成。公开源码不得包含所有者的密码或校验值。

默认打开 http://127.0.0.1:4318/workbench 。资料运营台位于同一地址的 `/ops`，共享本地登录。此服务仅监听本机回环地址，不作为公网或多人系统使用。

本地原件支持 PDF、PNG、JPEG；上传和预览不需要 AI 密钥。分类按钮只在主动点击时调用 API，无后台分类轮询。没有密钥、调用失败或预算用完，都可以点击“人工分类”继续处理。

## 个人配置、业务数据与更新

- 源代码：`platform/`。
- 个人配置：仓库根目录 `.local/personal/settings.json`，含登录校验值及可选 API 密钥；仅保存在本机，文件权限 0600。
- 业务数据：仓库根目录 `.local/dop/`，包含专用 PostgreSQL 数据目录、原件与运行配置。
- 不同演示实例：启动前设定绝对路径 `DOP_LOCAL_HOME`、未占用的 `DOP_LOCAL_APP_PORT` 和 `DOP_LOCAL_DATABASE_PORT`。多个实例默认共用个人配置，因此账号密码与 AI 预算记录不因新建演示数据库而重置。
- 如果指定 `DOP_LOCAL_CONFIG_HOME`，setup 与首次 start 必须使用同一绝对路径。首次启动保存了实例配置，之后继续沿用它。

不要删除 `.local` 来“更新版本”或“重置演示”。需要空白演示时，新建独立实例并保留原目录；不覆盖原有数据。已有本地实例启动时会顺序应用尚未执行的本地迁移；已执行迁移的内容改变会被拒绝。

正常更新：停止本地实例，备份，更新代码并安装依赖，再启动同一实例。保留原分支或提交，数据库升级后如需回退，使用同一份备份及对应旧代码，不能只回退代码后假定数据库兼容。

```sh
node scripts/local/runtime.mjs stop
node scripts/local/runtime.mjs backup
node scripts/local/runtime.mjs start
```

如使用了自定义 `DOP_LOCAL_HOME`，上述每条命令均须带相同变量。backup 要求应用与专用数据库均已停止，复制数据与个人配置并核对原件摘要。备份含个人凭据，必须私人保存。当前已完成一次冷备份及原件核对；跨机器恢复仍待验证，不能据此删除云端唯一副本。

## AI 设置及费用

在员工台左下方“本机 AI 设置”填写密钥并保存一次。密钥不会出现在登录表单或接口返回中。使用 `gpt-5.6-sol`、原项目 Responses 接口、原件 PDF/图片及严格结构化输出；本地增加无法可靠归类时弃权和期间冲突复核。

本次批准的验收限定为 6 份虚构文件、最多 6 次生成请求、USD 3 总预算，不自动重试。当前所有者的累计上限仍为 3 美元／6 次，已用完，不会自动追加；后续本人可以在界面主动提高累计上限，最多设为 100 美元／200 次，历史记录不会清零。调用前预留每次 USD 0.50、检查输入 token 上限及输出限制；网络失败或结果不明不退回预留额度，防止重复消耗。记录属于本应用，不限制其他程序使用同一 API 账户的费用；费用估算不等于供应商账单。

输入预检失败时不继续生成。意外断电遗留的调用锁会停止后续调用，仍可人工处理；核对调用记录后再由维护者处理锁，不会自动放行或无限重试。

## 功能与边界

已接回员工台今日待办、新建客户、进行中和已完成；运营台接回今日工作、任务、Case、复核与核心问题操作。未解决缺件、复核或开放问题会阻止交接。重复上传和交接按原幂等规则处理，排除文件仍保留原件。交接清单可从详情页打开，用浏览器打印保存 PDF。

本地“请客户补充”只保存待补问题，不发送邮件或远程链接；本人收取补交文件后上传、复核并关闭问题。远程客户入口、邮件催收、云连接器、多用户和云治理的原代码保留，但不在本地启用。运营台未接通的云管理菜单不作为本次交付要求。

标准及独立非示例文件的真实 AI 与人工流程、重复操作、未处理异常阻断、重启保留已实测。六份真实 API 文件均符合本轮预期，估算 token 费用 USD 0.072684；它不是大样本准确率证明，也不重新授予旧 M44 的类型级质量认证。公开候选包已在本机独立目录、全新数据库及独立账号下安装验收：406 项自动测试、12 项浏览器检查通过；依赖安装使用本机 pnpm 缓存，跨机器恢复和其他操作系统仍未验证。旧 M48 的远程多人、外部零指导计时和商业效果证明不属于新的结束条件。
